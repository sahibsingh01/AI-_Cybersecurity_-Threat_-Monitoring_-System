# AI-_Cybersecurity_-Threat_-Monitoring_-System


## Overview

This project is an end-to-end cybersecurity monitoring solution developed using Databricks and PySpark. It follows the Medallion Architecture (Bronze, Silver, and Gold) to process synthetic cybersecurity data and create an interactive dashboard for security monitoring.

---

## Technologies Used

- Databricks
- PySpark
- Spark SQL
- Delta Lake
- Python
- GitHub

---

## Project Workflow

1. Created synthetic cybersecurity datasets.
2. Stored raw data in the Bronze layer.
3. Cleaned and transformed data in the Silver layer.
4. Joined the datasets in the Gold layer.
5. Built an interactive Databricks dashboard.

---

## Datasets

- Users
- Devices
- Login Logs
- Threat Alerts

---

## Dashboard Features

- Total Login Attempts
- Successful Logins
- Failed Logins
- Login Status Distribution
- Recent High-Risk Login Events
- Risk Level Distribution
- Department-wise Login Activity
- Security Alerts by Type
- Device Type Distribution
